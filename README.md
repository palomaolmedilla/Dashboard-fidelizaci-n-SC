# Dashboard Fidelización SC

Panel estático de retención de socios con datos ficticios, importación CSV, filtros y exportación de seguimiento.

## Render
Crear un Static Site conectado a este repositorio. Build Command: `echo "Static site ready"`. Publish Directory: `.`. Branch: `main`.

## Datos
Los CSV se procesan únicamente en memoria en el navegador. No se envían a servidores ni se sincronizan. Las marcas de contacto duran durante la sesión de la página. No incluir datos personales en este repositorio público.

La plantilla y las definiciones de cada métrica están disponibles dentro del dashboard.
